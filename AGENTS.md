# Repository instructions

## Purpose

This repository is a general-purpose workspace for Codex cloud tasks. No application framework or dependency set has been selected yet.

## Working conventions

- Respond to the user in Chinese unless they request another language.
- Read the existing files before changing them and preserve unrelated work.
- Choose tools and dependencies based on the requested project; do not assume a framework.
- When adding a project, document its setup, run, and verification commands in README.md and commit appropriate dependency lockfiles.
- Run checks relevant to the changes. Report what was verified and any remaining limitations.
- Keep credentials, private documents, and local configuration out of commits. Use the cloud environment's configuration for required credentials.

## Current verification

This starter repository contains documentation and ignore rules only; it has no application build or test command yet.
